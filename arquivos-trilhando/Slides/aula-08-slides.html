MÓDULO 08 • INTEGRAÇÃO COM IA GENERATIVA

Arquitetura Flet + Gemini + Contexto

Integrando Inteligência Artificial Generativa aos Aplicativos com Arquivo de Contexto GEMINI.md

🔑

Google GenAI SDK

Conectando o aplicativo em Python à API do Gemini usando a chave de API (API Key).

📄

O Arquivo GEMINI.md

Definindo as diretrizes, personalidade, regras de resposta e conhecimento específico do seu app.

🚀

Sistema RAG Simplificado

Injetando o conteúdo do GEMINI.md no prompt do modelo como instrução de sistema (System Instruction).

CONCEITO 1 • CONEXÃO DE API

Conectando o Python à API do Gemini

Importando o SDK oficial google-genai

from google import genai import os # Configurando o cliente da API client = genai.Client(api_key=os.environ.get("GEMINI_API_KEY")) # Chamada básica ao modelo Gemini 2.5 Flash response = client.models.generate_content( model='gemini-2.5-flash', contents='Dê 3 dicas para economizar água na escola.' ) print(response.text)
CONCEITO 2 • CONTEXTO E PROMPT DE SISTEMA

O Arquivo de Contexto GEMINI.md

Como especializar a IA para responder de acordo com a proposta do seu ODS

📄 Estrutura do GEMINI.md

# IDENTIDADE DO BOT Você é o "EcoBot", um assistente virtual especialista no ODS 11 (Cidades Sustentáveis). # REGRAS DE RESPOSTA - Use tom motivador e linguagem acessível. - Respostas com no máximo 3 parágrafos. - Sempre sugira 1 ação prática.

💻 Injetando o Contexto no Código

with open("GEMINI.md", "r", encoding="utf-8") as f: contexto_sistema = f.read() response = client.models.generate_content( model='gemini-2.5-flash', contents=pergunta_usuario, config={'system_instruction': contexto_sistema} )
CONCEITO 3 • FLUXO DE DADOS

Arquitetura de Dados em Tempo Real

Da digitação do usuário na tela Flet até a resposta da IA

1️⃣

Interface (Flet)

Usuário digita a dúvida no TextField e clica no botão.

2️⃣

Carregamento

Exibe indicador de carregamento (ProgressRing) na tela.

3️⃣

API Gemini

Envia o prompt + contexto do GEMINI.md via SDK.

4️⃣

Renderização

Exibe a resposta gerada com formatação Markdown no Flet.
