FUNDAMENTOS DE IA

A Inteligência Artificial como Parceira de Código

Como usar o Gemini CLI para acelerar seu aprendizado e gerar código funcional

🤖 O Papel da IA no Aprendizado

  • Gera a estrutura inicial do código em segundos.
  • Ajuda a encontrar, explicar e corrigir erros (bugs).
  • Explica linhas complexas com analogias didáticas adaptadas a você.

⚠️ O Perigo da Falta de Clareza

  • A IA não lê pensamentos: ela exige instruções precisas e sem ambiguidade.
  • Um pedido vago gera código quebrado, incompatível ou respostas inadequadas.
  • Quem domina a instrução (prompt), domina o resultado!
ENGENHARIA DE PROMPTS

O Que é um "Prompt"?

A ponte de comunicação e comandos entre a intenção humana e a inteligência da máquina

🗺️

1. Contexto

Explique o cenário e quem a IA deve incorporar. Diga qual é a finalidade do projeto e para quem ele se destina.

🛡️

2. Regras

Dite as restrições inegociáveis. Ex: "não use bibliotecas externas", "deve rodar na tela preta do terminal".

📐

3. Formato

Especifique exatamente a saída: código Python limpo comentado, explicação passo a passo ou tabela.

METODOLOGIAS DE PROMPTING

Frameworks P.R.R.E e P.R.O.M.P.T

Fórmulas prontas e estruturadas para fazer pedidos profissionais à IA Generativa

📌 MÉTODO P.R.R.E
• P - Personagem: Dê um papel de autoridade.
• R - Realizações: Defina a experiência prévia.
• R - Requisição: O que você precisa exatamente.
• E - Exemplo: Mostre um modelo do resultado.

# PROMPT DE EXEMPLO COMPLETO: "Atue como programador Python sênior com 10 anos de experiência. Crie um script simples que peça a idade com input() e imprima com print() quantos dias de vida a pessoa viveu aproximadamente (idade * 365)."
⚙️ MÉTODO P.R.O.M.P.T
• Persona / Roteiro: Quem ela é e qual a tarefa.
• Objetivo / Modelo: Qual o propósito e formato final.
• Panorama / Transformar: O contexto e os ajustes.

# PROMPT DE EXEMPLO COMPLETO: "Atue como mentor didático de Python. Meu objetivo é aprender a usar input() e print(). Panorama: sou estudante do CEFET iniciando hoje. Formato: me dê 1 exemplo prático comentado sem usar bibliotecas difíceis."

DECIFRANDO O CÓDIGO • PRINT

Decifrando o Código: O Comando print()

Como o computador fala com você e como personalizar mensagens alterando as aspas

📢 A Voz do Computador

  • O print() é a função nativa em Python responsável por exibir mensagens na tela preta do terminal.
  • 🔑 A Regra das Aspas: Tudo o que estiver entre "aspas" ou 'aspas' é texto livre e pode ser modificado por você sem quebrar a lógica!
  • f-strings: Permite colocar dados formatados direto entre chaves f"Olá {nome}".
🐍 comando_print.py
# Imprimindo linhas e mensagens print("========================================") print("🚀 BEM-VINDO AO CEFET-MG!") print("========================================") nome = "Ana Clara" print(f"Estudante: {nome} | Módulo: Python 101")

DECIFRANDO O CÓDIGO • VARIÁVEIS

Decifrando o Código: Variáveis

A caixa com etiqueta que guarda informações para usar depois

📦 A Caixa com Etiqueta

  • Uma variável guarda um valor na memória do computador para usarmos depois.
  • O sinal = significa "guarde isso aqui" (não é o "igual" da matemática).
  • Você escolhe o nome (a etiqueta): nome, idade, pontos. Sem espaços e sem acentos!
  • Pode trocar o conteúdo a qualquer momento: pontos = pontos + 10.
🐍 variaveis.py
# Criando variáveis jogador = "Lucas" pontos = 0 print(f"Jogador: {jogador} | Pontos: {pontos}") # Trocando o valor da caixa pontos = 50 print(f"Jogador: {jogador} | Pontos: {pontos}")
DECIFRANDO O CÓDIGO • INPUT

Decifrando o Código: O Comando input()

Capturando a digitação do usuário e tornando seus programas interativos

⌨️ Escutando o Teclado

  • O input("Pergunta: ") pausa a execução e espera o usuário digitar a resposta.
  • Regra do Texto: O input() sempre devolve o valor como Texto (str).
  • Para fazer contas numéricas, convertemos com int(input(...)) ou float(input(...)).
🐍 comando_input.py
# Lendo o nome (texto) nome = input("Qual o seu nome? ") # Lendo ano de nascimento e convertendo para int ano_nasc = int(input("Qual seu ano de nascimento? ")) # Calculando idade idade = 2026 - ano_nasc print(f"\nOlá {nome}! Em 2026 você completa {idade} anos.")
