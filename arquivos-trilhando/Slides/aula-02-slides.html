Nivelamento em 4 linhas

Arquivo: nivelamento.py — professor digita, alunos copiam junto

# O computador me conhece! nome = input("Qual é o seu nome? ") idade = input("Quantos anos você tem? ") print(f"Olá, {nome}! Você tem {idade} anos!")

🔑 O que é o f antes das aspas?

O f ativa as f-strings — ele permite que você coloque variáveis dentro do texto usando {nome_da_variavel}.

CONCEITO 1 • TIPOS DE DADOS

Tipos de Dados e Conversão

input() sempre retorna texto — converta quando precisar de número

TipoO que guardaComo obter do input()
strTexto: "Ana", "sim"Padrão (não converte)
intInteiro: 16, 100int(input(...))
floatDecimal: 1.75, 9.5float(input(...))

💀 Sem conversão — resultado errado!

print(input("N1: ") + input("N2: ")) # "5" + "3" = "53" ← juntou texto!

✅ Com int() — resultado correto!

print(int(input("N1: ")) + int(input("N2: "))) # 5 + 3 = 8 ← soma numérica!

Só o if — O começo de tudo

Arquivo: decisao_passo1.py — temática: seguidores nas redes sociais

# Você tem seguidores suficientes? seguidores = int(input("Quantos seguidores você tem? ")) if seguidores >= 10000: print("🌟 Você é INFLUENCER!")

📐 A Regra da Indentação

O espaço de 4 posições (ou Tab) antes do print() é obrigatório. Ele diz ao Python: "essa linha pertence ao if".

Live Coding — Passo 3 de 3 (Forma completa!)

if + elif + else

Arquivo: decisao_passo3.py — classificador de perfil nas redes sociais

seguidores = int(input("Quantos seguidores? ")) if seguidores >= 100000: print("🏆 MEGA INFLUENCER!") elif seguidores >= 10000: print("🌟 Influencer confirmado!") elif seguidores >= 1000: print("📱 Microinfluencer!") else: print("🌱 Todo grande começou do zero.")

🧠 Como o Python pensa?

Testa condição a condição, de cima para baixo. Na primeira verdadeira, executa e pula as demais. Posso ter quantos elif quiser!
