MÓDULO 04 • AUTOMAÇÃO & LOOPS

Laços de Repetição

Automatizando tarefas repetitivas com while, for e range()

🔄

Loop while

Repete enquanto uma condição for verdadeira. Ideal quando não sabemos o número exato de repetições.

🔢

Loop for

Itera sobre uma sequência ou intervalo definido de vezes com o auxílio de range().

📊

Contadores e Acumuladores

Técnicas de contagem e somatório incremental dentro de laços de repetição.

CONCEITO 1 • LOOP WHILE

O Laço while (Enquanto)

Repetição baseada em uma condição lógica dinâmica

⚠️ Perigo do Loop Infinito!

Se a variável de controle não for atualizada dentro do bloco, o programa travará rodando para sempre.

💻 Exemplo com Contador

contador = 1 while contador <= 5: print(f"Tentativa número {contador}") contador += 1 # Incremento essencial! print("Fim do laço!")
CONCEITO 2 • LOOP FOR E RANGE

O Laço for e a Função range()

Iterando sobre sequências numéricas de forma simples e segura

📌 Entendendo o range()

  • range(5) ➔ 0, 1, 2, 3, 4
  • range(1, 6) ➔ 1, 2, 3, 4, 5
  • range(0, 10, 2) ➔ 0, 2, 4, 6, 8 (passo 2)

💻 Exemplo Prático

# Imprimindo a tabuada do 5 for i in range(1, 11): resultado = 5 * i print(f"5 x {i} = {resultado}")
CONCEITO 3 • PADRÕES DE CÓDIGO

Acumuladores e Somatórios

Somando múltiplos dados inseridos pelo usuário

soma_total = 0.0 for item in range(1, 4): preco = float(input(f"Digite o preço do produto {item}: R$ ")) soma_total += preco # Equivalente a: soma_total = soma_total + preco print(f"🛒 Total da compra: R$ {soma_total:.2f}")
