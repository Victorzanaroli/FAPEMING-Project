🧩 Tópico 1 • Funções — Explicação (1/2)

Por que criar Funções? O Comando def

Regra DRY (Don't Repeat Yourself): em vez de repetir o mesmo bloco 10 vezes, crie uma receita e chame pelo nome!

😫 Sem Função (Código repetido e difícil de mudar)

print("====================") print("🎮 BEM-VINDO AO JOGO") print("====================") # Se precisar mostrar 5 vezes, terá que copiar tudo!

✨ Com Função def (Definir 1x, Chamar sempre!)

# 1. DEFINIR (ensina a receita ao Python): def mostrar_painel(): print("====================") print("🎮 BEM-VINDO AO JOGO") print("====================") # 2. CHAMAR (coloca a função em ação!): mostrar_painel() mostrar_painel()
⚠️ Atenção: Só escrever def mostrar_painel(): não imprime nada na tela! A função só roda quando chamamos mostrar_painel() com parênteses embaixo!
🧩 Tópico 1 • Funções — Explicação (2/2)

Passando Ingredientes: Parâmetros da Função

Parâmetros ficam dentro dos parênteses ( ) e permitem que a função trabalhe com dados diferentes a cada chamada!

1️⃣ Função com 1 Parâmetro

def saudar_jogador(nome): print(f"⚔️ Olá, {nome}! Prepare-se!") # Cada chamada envia um nome diferente: saudar_jogador("Ana") saudar_jogador("Lucas")

2️⃣ Função com 2 ou mais Parâmetros

def apresentar_heroi(nome, nivel): print(f"🛡️ Herói: {nome} | Nível: {nivel}") apresentar_heroi("Zelda", 15) apresentar_heroi("Link", 20)

💡 Separe os parâmetros com vírgula , e envie na mesma quantidade quando chamar!

🎁 Tópico 2 • Retorno (return) — Explicação (1/2)

A Diferença entre print() e return

O print() apenas mostra na tela e esquece; o return entrega o valor para guardarmos em uma variável!

📺 Apenas print() (Não devolve o valor)

def somar_sem_return(a, b): print(a + b) # Mostra 8 na tela, mas NÃO entrega para a variável! resultado = somar_sem_return(5, 3) print(resultado) # → Imprime None (Vazio!)

🎁 Com return (Devolve o resultado real!)

def somar(a, b): return a + b # Agora a variável 'total' recebe o número 8! total = somar(5, 3) print(f"O dobro da soma é: {total * 2}") # → 16!
🎁 Tópico 2 • Retorno & Escopo — Explicação (2/2)

Escopo Local: O que nasce na função, fica na função!

Variáveis criadas dentro do def são invisíveis fora dele — por isso usamos o return para tirar o resultado de lá!

🚨 O Erro Clássico: NameError

def calcular_bonus(pontos): bonus = pontos * 2 # 'bonus' nasceu aqui dentro! return bonus # ERRADO: tentar imprimir 'bonus' direto fora da função # print(bonus) → 💥 NameError: 'bonus' is not defined! # CERTO: guardar o retorno da função em uma variável! meu_premio = calcular_bonus(50) print(f"Prêmio final: {meu_premio}") # → 100!

🧮 Exemplo Prático: Calculadora de Média

def calcular_media(n1, n2): media = (n1 + n2) / 2 return media nota_final = calcular_media(8.0, 9.0) if nota_final >= 7.0: print(f"🎉 Aprovado com média {nota_final}!") else: print(f"📚 Média {nota_final}: Estude mais!")

🗂️ Tópico 3 • Dicionários — Explicação Básica (1/2)

Lista vs Dicionário: O Poder do {chave: valor}

Na lista buscamos pelo número da posição [0]; no Dicionário buscamos pelo nome da etiqueta (chave)!

🤔 Com Lista (O que significa cada número?)

heroi_lista = ["Link", 100, 50, "Espada"] # O que é 100? É a vida, o nível ou o ouro? print(heroi_lista[1])

🗂️ Com Dicionário { } (Tudo Etiquetado!)

heroi = { "nome": "Link", "vida": 100, "ouro": 50, "arma": "Espada" } print(heroi["nome"]) # → Link print(heroi["vida"]) # → 100
🗂️ Tópico 3 • Dicionários — Explicação Básica (2/2)

Alterando Valores, Criando Chaves e Proteção com .get()

Dicionários NÃO usam .append()! Basta atribuir dicionario["nova_chave"] = valor

✏️ Atualizando e Criando Chaves

pet = {"nome": "Rex", "fome": 50} # 1. Alterando uma chave que já existe: pet["fome"] = 10 # 2. Criando uma chave NOVA na hora: pet["brinquedo"] = "Bolinha" print(pet) # {'nome': 'Rex', 'fome': 10, 'brinquedo': 'Bolinha'}

🛡️ Evitando o KeyError com .get()

# Se a chave não existir, colchetes dão erro: # print(pet["cor"]) → 💥 KeyError: 'cor' # Com .get(), se não existir, devolve o aviso padrão: print(pet.get("cor", "Cor não cadastrada"))

💡 Use dicionario.get("chave", "padrão") sempre que não tiver certeza se a chave existe!

A Dupla de Ouro: Lista de Dicionários!

Como o Instagram, o Spotify e o iFood guardam dados? Uma Lista onde cada item é um Dicionário!

cardapio = [ {"item": "Pizza", "preco": 40.0}, {"item": "Suco", "preco": 8.0}, {"item": "Açaí", "preco": 18.0} ] # Percorrendo tudo com um simples for: for produto in cardapio: print(f"🍽️ {produto['item']} custa R$ {produto['preco']}")
