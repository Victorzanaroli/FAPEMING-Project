🛡️ Tópico 1 • Explicação (1/2) — Tratamento de Erros

Por que o programa quebra? Conheça o try / except

Quando o usuário digita algo inesperado, o Python para tudo — a menos que você coloque um escudo!

💥 Sem Proteção (O Programa Trava)

idade = int(input("Sua idade: ")) # Se o usuário digitar "quinze" ou "abc": # ❌ ValueError: invalid literal for int() # O programa fecha na hora e perde tudo!

Qualquer linha abaixo do erro nunca chega a ser executada porque o Python interrompe o script imediatamente.

🛡️ Anatomia do Escudo try / except

  • try: (Tentar) — Colocamos aqui dentro as linhas "perigosas" que dependem do que o usuário vai digitar.
  • except: (Exceção) — É o "Plano B": só executa se acontecer algum erro dentro do bloco try!

⚠️ Os 2 Erros Mais Comuns de Entrada:

  • ValueError: tentar converter letras ou vazio em int() ou float() (ex: digitar "dez" ou 1,75 com vírgula).
  • ZeroDivisionError: tentar dividir qualquer número por 0.
Tópico 1 • Explicação (2/2) — Live Coding no VS Code (aula03_try.py)

Na Prática: Blindando com try e except

Veja como proteger a leitura de dados sem deixar o programa fechar na cara do usuário!

💻 Código com Blindagem (aula03_try.py)

# 🛡️ Protegendo o programa contra letras em campos numéricos try: idade = int(input("Digite sua idade em números: ")) print(f"Ano que vem você terá {idade + 1} anos!") except ValueError: print("⚠️ Ei! Digite apenas números inteiros (ex: 14).")

🧠 Passo a Passo da Execução

  • Caminho Feliz: Se digitar 14, o try roda até o fim e o Python pula o except.
  • Caminho de Erro: Se digitar "catorze" na linha do int(), o Python pula imediatamente para o except ValueError: e mostra o aviso amigável!

🔁 Tópico 2 • Explicação (1/2) — Laço Condicional while

Como funciona o Laço while (Enquanto)?

Enquanto a condição for verdadeira (True), o Python repete o bloco de código sem parar!

🔢 Os 3 Elementos do while com Contador

# 1️⃣ INÍCIO: Criamos a variável antes do laço contador = 1 # 2️⃣ CONDIÇÃO: Repete enquanto for menor ou igual a 3 while contador <= 3: print(f"Volta número: {contador}") # 3️⃣ PASSO: Atualiza a variável para o laço avançar! contador = contador + 1

🧠 Quando usar o while?

  • Quando não sabemos quantas tentativas o usuário vai precisar (ex: digitar senha, jogar até acabar as vidas, menu interativo).
  • Ou quando queremos controlar manualmente um contador (somando + 1, + 2, etc.).

🚨 Cuidado com o Loop Infinito!

Se você esquecer o 3º elemento (atualizar a variável dentro do while), a condição será verdadeira para sempre! No terminal, aperte Ctrl + C para frear.

🚀 Tópico 3 • Explicação (1/2) — Repetição Contada com for

Entendendo o for e os Segredos do range()

Ao contrário do while, o for já cria e avança a variável contadora sozinho para você!

🎛️ As 3 Formas de Usar o range()

# 1. range(fim) → Começa do 0 e para antes do fim range(4) # Gera: 0, 1, 2, 3 # 2. range(início, fim) → Para 1 número ANTES do fim! range(1, 6) # Gera: 1, 2, 3, 4, 5 # 3. range(início, fim, passo) → Pula de N em N range(0, 10, 2) # Pares: 0, 2, 4, 6, 8 range(5, 0, -1) # Regressiva: 5, 4, 3, 2, 1

📌 Regra de Ouro do range(início, fim)

O número final é sempre exclusivo (o Python para um passo antes dele). Para contar de 1 até 10, escrevemos range(1, 11)!

⚡ while vs for: Qual escolher?

  • Use for quando souber quantas vezes vai repetir (ex: tabuada de 1 a 10, ler 5 notas).
  • Use while quando depender de uma condição incerta (ex: até acertar a senha).
Tópico 3 • Explicação (2/2) — Live Coding no VS Code

Na Prática: Laço for com range()

Veja como programar rodadas de um jogo e uma contagem regressiva de foguete!

🚀 Exemplo: Contagem Crescente e Regressiva

# 1. Repetindo 3 vezes (1, 2 e 3) for rodada in range(1, 4): print(f"🎮 Rodada nº {rodada}") # 2. Contagem regressiva (5 até 1) print("🚀 Lançamento em:") for seg in range(5, 0, -1): print(f"{seg}...") print("💥 DECOLAR!")

🔍 O que é a variável rodada ou seg?

A cada volta do laço, ela recebe automaticamente o próximo número entregue pelo range() — sem precisar fazer seg = seg - 1!

📋 Tópico 4 • Listas — Explicação Básica (1/2)

O Problema das 30 Variáveis & Índices Base 0

Em vez de criar aluno1, aluno2... guardamos tudo em uma única lista com colchetes [ ]!

😫 Sem Lista (Impossível escalar)

aluno1 = "Ana" aluno2 = "Bruno" aluno3 = "Carla" # Imagina 300 alunos!

🎉 Com Lista (Tudo em 1 variável!)

alunos = ["Ana", "Bruno", "Carla"] print(alunos[0]) # → Ana (1º item!) print(alunos[2]) # → Carla (3º item!) print(alunos[-1]) # → Carla (último item!)

🔢 Regra de Ouro: A Contagem Começa no ZERO!

Posição HumanaÍndice PythonValor Guardado
1º elementoalunos[0]"Ana"
2º elementoalunos[1]"Bruno"
3º elementoalunos[2]"Carla"
🚨 Cuidado com o IndexError: Se a lista tem 3 itens (índices 0, 1 e 2), tentar acessar alunos[3] quebra o programa!
📋 Tópico 4 • Listas — Explicação Básica (2/2)

Os 4 Comandos Essenciais de Toda Lista

Adicionar no fim (.append), remover por nome (.remove), remover por posição (.pop) e medir tamanho (len)

➕
lista.append(item) → Adiciona no FINALEx: playlist.append("Imagine")
🗑️
lista.remove(valor) → Remove pelo NOMEEx: playlist.remove("Imagine")
🎯
lista.pop(indice) → Remove pela POSIÇÃOEx: playlist.pop(0) (remove o 1º da fila)
📏
len(lista) → Conta quantos itens existemEx: print(len(playlist))
⌨️ Live Coding — playlist.py
playlist = [] # Começa vazia # Adicionando com .append() playlist.append("Bohemian Rhapsody") playlist.append("Blinding Lights") playlist.append("Evidências") print(f"Total: {len(playlist)} músicas") print("Primeira da fila:", playlist[0]) # Removendo pelo nome vs pela posição playlist.remove("Blinding Lights") tocando = playlist.pop(0) print("Tocando agora:", tocando) print("Restante na fila:", playlist)

🔥 Tópico 4 • Listas Avançado — Explicação (1/2)

Casamento Perfeito: Percorrendo Listas com for

Em vez de dar print(lista[0]), print(lista[1])... o laço for visita cada item sozinho!

1️⃣ Forma Direta: for item in lista:

A variável do for assume o valor de cada elemento da lista, um por volta:

jogos = ["Minecraft", "Roblox", "Valorant"] for jogo in jogos: print(f"🎮 Eu curto jogar: {jogo}")
💡 Funciona se a lista tiver 3 itens ou 3.000 itens!

2️⃣ Com Posição Numerada: enumerate()

Quer mostrar o número da posição junto com o nome? Use enumerate() com i + 1:

jogos = ["Minecraft", "Roblox", "Valorant"] for i, jogo in enumerate(jogos): print(f"{i + 1}º lugar: {jogo}") # Mostra: 1º lugar: Minecraft, 2º lugar: Roblox...
🎯 Somamos i + 1 para o usuário ver 1, 2, 3 em vez de 0, 1, 2!
🔥 Tópico 4 • Listas Avançado — Explicação (2/2)

Combinando Tudo: for + if / else + lista

Podemos preencher uma lista com for, filtrar itens com if/else e testar se algo está na lista com in!

🔍 Exemplo 1: Filtrando Notas com for + if/else
notas = [8.5, 4.0, 9.0, 5.5, 7.0] aprovados = [] for nota in notas: if nota >= 6.0: print(f"✅ Nota {nota}: APROVADO!") aprovados.append(nota) else: print(f"⚠️ Nota {nota}: Recuperação") print(f"Total de aprovados: {len(aprovados)}")
🎵 Exemplo 2: Busca Segura com if item in lista:
playlist = [] for i in range(3): m = input(f"Digite a {i+1}ª música: ") playlist.append(m) busca = input("Qual música quer remover? ") # O operador 'in' evita erro se a música não existir! if busca in playlist: playlist.remove(busca) print("✅ Removida! Nova lista:", playlist) else: print("❌ Essa música não está na playlist!")
