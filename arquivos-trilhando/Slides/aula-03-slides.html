Live Coding 1 — Abra o VS Code (aula03_try.py)

Escudo Anti-Erro: try e except

O que acontece se o usuário digitar "quinze" por extenso dentro do int()?

💻 Código com Blindagem (aula03_try.py)

# 🛡️ Protegendo o programa contra letras em campos numéricos try: idade = int(input("Digite sua idade em números: ")) print(f"Ano que vem você terá {idade + 1} anos!") except ValueError: print("⚠️ Ei! Digite apenas números inteiros (ex: 14).")

🧠 Como funciona?

  • try: O Python tenta executar as linhas de dentro.
  • except ValueError: Só roda se der erro na conversão numérica!
❓ Pergunta para a Turma
Se eu digitar 14 certinho, a mensagem do except vai aparecer?
→ Não! Quando não há erro no try, o except é totalmente ignorado!

Live Coding 2 — Repetição com Condição (aula03_loops.py)

Laço while — Repetir Enquanto...

Ideal para menus, jogos e validação de senha até o usuário acertar!

🔑 Exemplo: Cofre com Senha Secreta

senha_correta = "python123" tentativa = "" while tentativa != senha_correta: tentativa = input("🔑 Digite a senha secreta: ") if tentativa != senha_correta: print("❌ Senha incorreta! Tente de novo.") print("🔓 Acesso liberado com sucesso!")

🛑 Comando break (Freio de Emergência)

Se usarmos while True: (loop contínuo), podemos parar e sair do laço a qualquer momento usando o comando break!

⚠️ Cuidado com o Loop Infinito!

Dentro do while, algo precisa mudar (como ler uma nova tentativa ou somar cont += 1) para o loop terminar!

🎯 Mini-Desafio 2 — 3 minutos

Sua vez com o while!

Crie um contador automático de 1 até 5

⏱️ 3 minutos

🔢 Desafio: Contador de 1 a 5

Crie um programa que:

  • Comece com contador = 1
  • Use while contador <= 5: para imprimir o número atual
  • Some 1 a cada volta com contador = contador + 1 (ou contador += 1)

Estrutura do Contador:

Live Coding 3 — Contagem Programada

Laço for com range()

Quando você sabe exatamente quantas vezes quer repetir!

🚀 Exemplo: Contagem Regressiva e Tentativas

# 1. Repetindo 3 vezes (1, 2 e 3) for rodada in range(1, 4): print(f"🎮 Rodada nº {rodada}") # 2. Contagem regressiva (5 até 1) print("🚀 Lançamento em:") for seg in range(5, 0, -1): print(f"{seg}...") print("💥 DECOLAR!")

📌 Regra de Ouro do range(início, fim)

O range(1, 4) começa no 1 e para ANTES do 4 (gera 1, 2, 3). Sempre coloque 1 número a mais no fim!

⚡ Mini-Desafio Rápido (2 min):

Use for i in range(1, 4): para imprimir 3 vezes no terminal: "Minha mensagem nº X"!

🔍 Bloco 3 — Engenharia Reversa (Missão Detetive)

Analisando o "Arcade Passatempo"

Descubra onde o loop se repete, onde o erro é tratado e quando o jogo acaba!

vidas = 3 pontos = 0 print("🎮 BEM-VINDO AO DESAFIO DA SORTE!") while vidas > 0: print(f"\n❤️ Vidas: {vidas} | ⭐ Pontos: {pontos}") try: chute = int(input("Adivinhe o número (1 a 5): ")) if chute < 1 or chute > 5: print("⚠️ Fora do intervalo (1 a 5)!") continue if chute == 3: print("🎉 ACERTOU! +100 pontos!") pontos += 100 else: print("❌ Errou! Perdeu 1 vida.") vidas -= 1 except ValueError: print("🚨 Digite apenas números inteiros!") print(f"\n💥 GAME OVER! Pontuação: {pontos}")
🕵️ Perguntas de Detetive
1. O que acontece se o jogador digitar "três" por extenso?
→ Cai no except ValueError, mostra o alerta e não perde vida!
2. Qual linha impede que o jogador perca vida se digitar 9?
→ O if chute < 1 or chute > 5: junto com o continue!
3. O que faz o laço while parar de rodar?
→ Quando a variável vidas chega a 0 após 3 chutes errados!
