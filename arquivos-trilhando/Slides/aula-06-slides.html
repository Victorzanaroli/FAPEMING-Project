MÓDULO 06 • MODULARIZAÇÃO

Funções e Reutilização de Código

Empacotando lógica com def, parâmetros e valores de retorno return

🧩

O que é uma Função?

Um bloco de código nomeado que realiza uma tarefa específica e pode ser executado várias vezes.

📥

Parâmetros (Entradas)

Variáveis recebidas pela função para personalizar seu comportamento dinamicamente.

📤

Retorno (return)

O resultado final calculado pela função enviado de volta para quem a chamou.

CONCEITO 1 • DEFINIÇÃO DE FUNÇÃO

Definindo uma Função com def

Sintaxe limpa e legível

📌 Regra DRY (Don't Repeat Yourself)

Se você escreveu o mesmo bloco de código mais de duas vezes, transforme-o em uma função!

💻 Exemplo Simples

# Definição da função def exibir_saudacao(nome): print(f"👋 Olá {nome}, bem-vindo(a) ao laboratório!") # Chamadas da função exibir_saudacao("Gabriel") exibir_saudacao("Larissa")
CONCEITO 2 • RETORNO DE VALORES

Diferença entre print() e return

Como reaproveitar o resultado de um cálculo em outras partes do sistema

⚠️ Apenas Imprime (Sem Retorno)

def somar_bad(a, b): print(a + b) res = somar_bad(4, 5) # res é None! Não dá pra usar em cálculos.

✅ Retorna o Valor (Com return)

def somar_good(a, b): return a + b res = somar_good(4, 5) total = res * 2 # total = 18! Funciona perfeitamente.
