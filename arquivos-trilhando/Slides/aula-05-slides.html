📱 Tópico 1 • Flet Básico — Explicação (1/2)

Adeus Tela Preta! Como funciona o Flet?

Com import flet as ft, a função main(page: ft.Page) vira a janela do nosso aplicativo!

⌨️ Esqueleto Mínimo — meu_primeiro_app.py
import flet as ft def main(page: ft.Page): page.title = "Meu Primeiro App!" # Criamos um texto visual e penduramos na página: titulo = ft.Text("🚀 Olá, Mundo Visual!", size=28) page.add(titulo) ft.app(target=main)
🪟
page: ft.Page → A Janela em BrancoÉ o quadro onde configuramos o título (page.title) e adicionamos componentes.
➕
page.add(...) → Coloca na TelaSem page.add(), o componente fica só na memória e não aparece na janela!
▶️
ft.app(target=main) → Liga o MotorÉ a última linha do arquivo que abre a janela gráfica do aplicativo.

Veja a tradução direta do que fazíamos no terminal para os componentes visuais do Flet!

🖱️ Tópico 2 • Eventos & Layouts — Explicação (1/2)

Dando Vida ao Botão: on_click e page.update()

Quando o usuário clica no botão, uma função def lê o .value, altera a tela e chama page.update()!

⚡ Como conectar o clique do botão:
nome_input = ft.TextField(label="Qual é o seu nome?") resposta = ft.Text("", size=20, color="cyan") # 1. Função que roda quando o botão é clicado: def saudar(e): resposta.value = f"🎉 Olá, {nome_input.value}!" page.update() # OBRIGATÓRIO para atualizar a tela! # 2. Passamos o nome da função SEM parênteses no on_click: btn = ft.ElevatedButton("Dizer Olá", on_click=saudar) page.add(nome_input, btn, resposta)

🚨 As 2 Pegadinhas Mais Comuns no Flet:

1. Esquecer o page.update(): Se você mudar resposta.value mas não chamar page.update(), a tela continua igualzinha!

2. Colocar parênteses no on_click: Escreva on_click=saudar (sem ()), senão a função roda antes de clicar!

🖱️ Tópico 2 • Eventos & Layouts — Explicação (2/2)

Organizando a Tela: ft.Column (Vertical) vs ft.Row (Horizontal)

Use Column para empilhar um abaixo do outro e Row para colocar elementos lado a lado!

⬇️ ft.Column([...]) → Empilha na Vertical

coluna = ft.Column([ ft.Text("Título em cima"), ft.TextField(label="Campo no meio"), ft.ElevatedButton("Botão embaixo") ], spacing=15)

➡️ ft.Row([...]) → Alinha Lado a Lado

linha_botoes = ft.Row([ ft.ElevatedButton("➕ Somar"), ft.ElevatedButton("➖ Subtrair"), ft.ElevatedButton("🧹 Limpar") ], alignment=ft.MainAxisAlignment.CENTER)

Treino Relâmpago: Contador de Cliques Gamer

Crie dois botões lado a lado em um ft.Row (+1 Ponto e Zerar) que atualizam o placar na tela!

🎮 Siga os passos no VS Code:

  1. Crie um placar = ft.Text("0", size=40).
  2. Crie a função def somar(e): que converte int(placar.value) + 1, atualiza placar.value e chama page.update().
  3. Coloque os botões de Somar e Zerar lado a lado dentro de um ft.Row([...])!
import flet as ft def main(page: ft.Page): page.title = "Contador Gamer" placar = ft.Text("0", size=45, weight="bold") def ganhar_ponto(e): placar.value = str(int(placar.value) + 1) page.update() def zerar(e): placar.value = "0" page.update() page.add( placar, ft.Row([ ft.ElevatedButton("⚡ +1 Ponto", on_click=ganhar_ponto), ft.ElevatedButton("🔄 Zerar", on_click=zerar) ]) ) ft.app(target=main)

🔥 Tópico 4 • Multi-Telas & Listas no Flet — Explicação (1/2)

Navegação de App Mobile com ft.NavigationBar

Como ter 2 ou 3 abas no mesmo app? Criamos um container para cada aba e alternamos .visible = True / False!

🧭 Alternando Telas com .visible
tela_inicio = ft.Column([ft.Text("🏠 Aba Início")], visible=True) tela_sobre = ft.Column([ft.Text("ℹ️ Sobre a Dupla")], visible=False) def mudar_aba(e): idx = e.control.selected_index tela_inicio.visible = (idx == 0) tela_sobre.visible = (idx == 1) page.update() page.navigation_bar = ft.NavigationBar( on_change=mudar_aba, destinations=[ ft.NavigationBarDestination(icon=ft.Icons.HOME, label="Início"), ft.NavigationBarDestination(icon=ft.Icons.INFO, label="Sobre") ] ) page.add(tela_inicio, tela_sobre)

💡 Por que essa técnica é tão boa?

Não apaga o que o usuário já digitou! Quando clicamos na aba 0, mostramos tela_inicio e escondemos tela_sobre; na aba 1, fazemos o inverso!

🔥 Tópico 4 • Multi-Telas & Listas no Flet — Explicação (2/2)

Adicionando Itens Dinamicamente na Tela com .controls.append()

Quando o usuário cadastra algo, guardamos na nossa lista Python e adicionamos um novo ft.Text na Column!

📋 Lista Dinâmica na Interface Visual
dados = [] campo = ft.TextField(label="Novo item...") lista_visual = ft.Column() # Começa vazia na tela def adicionar(e): if campo.value.strip() != "": dados.append(campo.value) # Adiciona um novo Text visual dentro da Column: lista_visual.controls.append( ft.Text(f"✅ {campo.value} (Total: {len(dados)})") ) campo.value = "" # Limpa a caixa page.update()

🔗 Tudo se Conecta!

Veja como usamos exatamente o que aprendemos nas aulas anteriores:
• if / else valida se o campo não está vazio.
• dados.append() salva na lista Python.
• lista_visual.controls.append() desenha o item na tela do Flet!

Desafio Mestre: App Completo com Lista, try/except e Tema

Construa um aplicativo visual que cadastra itens, valida erros e lista tudo na tela!

🎯 Checklist do seu App Flet:

  1. Janela com page.title, ThemeMode.DARK e tamanho mobile.
  2. Dois campos: nome_item (texto) e valor_item (número).

import flet as ft def main(page: ft.Page): page.title = "Controle Inteligente" page.theme_mode = ft.ThemeMode.DARK nome = ft.TextField(label="Descrição") valor = ft.TextField(label="Valor numérico") aviso = ft.Text("") historico = ft.Column() def salvar(e): try: v = float(valor.value) historico.controls.append(ft.Text(f"📌 {nome.value}: {v}")) aviso.value = "✅ Salvo com sucesso!" aviso.color = "green" except ValueError: aviso.value = "⚠️ Digite um número válido!" aviso.color = "red" page.update() page.add(nome, valor, ft.ElevatedButton("Adicionar", on_click=salvar), aviso, historico) ft.app(target=main)
