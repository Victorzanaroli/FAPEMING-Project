MÓDULO 05 • ESTRUTURAS DE DADOS

Listas e Coleções

Organizando múltiplos elementos em uma única estrutura sequencial

📋

O que é uma Lista?

Uma sequência ordenada de itens armazenados sob o mesmo nome de variável, demarcada por colchetes [].

🔢

Indexação (Índices)

Acesso rápido a cada elemento usando sua posição numérica, começando SEMPRE do índice 0.

🛠️

Métodos Dinâmicos

Adicionando, removendo e manipulando elementos com append(), pop() e len().

CONCEITO 1 • SINTAXE DE LISTAS

Criando Listas e Acessando Índices

A regra de ouro: O primeiro elemento fica na posição 0

📌 Conceito de Posição

frutas = ["Maçã", "Banana", "Laranja"] # ÍNDICES: 0 1 2
  • frutas[0] ➔ "Maçã"
  • frutas[2] ➔ "Laranja"
  • frutas[-1] ➔ Último elemento ("Laranja")

💻 Alterando Elementos

frutas[1] = "Morango" # Substitui "Banana" print(frutas) # Saída: ['Maçã', 'Morango', 'Laranja'] print(len(frutas)) # Tamanho da lista: 3
CONCEITO 2 • MÉTODOS DE LISTA

Manipulando Listas no Python

Adicionando e removendo elementos dinamicamente

append(valor)

Adiciona um novo elemento ao final da lista.

tarefas.append("Estudar Python")

remove(valor)

Remove a primeira ocorrência do valor especificado.

tarefas.remove("Estudar Python")

pop(indice)

Remove e retorna o elemento no índice informado.

item = tarefas.pop(0)
CONCEITO 3 • ITERAÇÃO

Percorrendo Listas com for

Processando elemento por elemento automaticamente

alunos_projeto = ["Carlos", "Beatriz", "Daniel", "Elena"] print("📋 Lista de Integrantes da Equipe:") for aluno in alunos_projeto: print(f" • Estudanate: {aluno}")
