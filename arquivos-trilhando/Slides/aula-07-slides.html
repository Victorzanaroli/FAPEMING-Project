MÓDULO 07 • INTERFACES VISUAIS (GUI)

Interfaces Gráficas com Flet

Construindo aplicativos visuais modernos para Web, Desktop e Mobile usando apenas Python

📱

O Framework Flet

Permite criar apps com o poder gráfico do Flutter usando sintaxe 100% Python simples.

🧩

Widgets Básicos

Textos (ft.Text), campos de entrada (ft.TextField) e botões (ft.ElevatedButton).

⚡

Eventos e Reatividade

Respondendo ao clique do usuário através de funções de evento (on_click) e atualizando a tela com page.update().

CONCEITO 1 • ESTRUTURA BASE

A Estrutura de um App Flet

O ponto de entrada e o objeto page

import flet as ft def main(page: ft.Page): page.title = "Meu Primeiro App ODS" page.padding = 20 # Adicionando um componente visual à página page.add(ft.Text("Olá, Mundo Flet!", size=24, weight="bold")) # Inicia o aplicativo ft.app(target=main)
CONCEITO 2 • LAYOUT & ORGANIZAÇÃO

Organizando Elementos: Column e Row

Dispondo componentes na vertical e na horizontal

ft.Column (Vertical)

Empilha elementos de cima para baixo.

ft.Column([ ft.Text("Título"), ft.TextField(label="Nome"), ft.ElevatedButton("Salvar") ])

ft.Row (Horizontal)

Alinha elementos lado a lado na mesma linha.

ft.Row([ ft.ElevatedButton("Sim"), ft.ElevatedButton("Não") ])
CONCEITO 3 • INTERATIVIDADE

Eventos de Clique e page.update()

Fazendo a interface responder às ações do usuário

def main(page: ft.Page): campo_nome = ft.TextField(label="Digite seu nome") texto_saida = ft.Text("", color="green") def ao_clicar(e): texto_saida.value = f"Bem-vindo(a), {campo_nome.value}!" page.update() # Re-renderiza a tela com o novo valor botao = ft.ElevatedButton("Entrar", on_click=ao_clicar) page.add(campo_nome, botao, texto_saida)
